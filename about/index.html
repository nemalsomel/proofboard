From idea to soldering, in four steps

One design all the way: what you draw and program is what you simulate, and the code comes from it too.

1

Design it

Place the parts and say what connects to what. The router lays the solder bridges, and on stripboard the track cuts too.

  • the Problems tab flags shorts, floating inputs and excess current
  • Compact rearranges a sparse layout into a smaller area
2

Program it

Build what the controller does from blocks: input, logic, clock, counter, timer, sequence, PWM output. A block refers to a pin on the board and the wiring supplies the GPIO, so it stays valid after a board swap.

  • existing Arduino or MicroPython code can be turned into blocks
  • Claude can put the blocks together and test them too
3

Try it

Start the simulation: the program runs, the button can be pressed, the potentiometer turned, the LED glows with its current, the motor turns and the display backlight comes on.

  • block wires and ports show their current values
  • GPIO levels and voltages are shown live
4

Build it

The program becomes MicroPython or Arduino code, or a PlatformIO project. Check the board from the copper side: where to cut, where the bridges go.

  • existing Arduino or MicroPython code can be read back into blocks
  • save the design to a file, or share it as a link

What's inside

Made for hobby and teaching circuits, with the rules of real boards.

Board and wiring

  • Dot-grid, tripad and stripboard of any size; component and copper side views
  • Connections with automatic routing, manual bridges and wires
  • Track cuts by hand or automatically from the connections
  • Compact: rearranges a sparse layout into a smaller area, with preview

Simulation and checks

  • DC simulation: LED, diode, transistor, MOSFET, capacitor, PWM
  • Motor, servo, stepper, displays, joystick, potentiometer
  • Checks: shorts, overcurrent, voltage ranges, wrong GPIO (e.g. analog signal without ADC)

Program and code

  • Blocks: input, logic, clock, counter, timer, sequence, PWM
  • Code generation for MicroPython and Arduino, with a PlatformIO project
  • Code import: a block program from an existing sketch

Parts

  • Controller boards: Raspberry Pi Pico W, ESP32 DevKit V1, ESP32-C3 SuperMini, with board swap
  • Modules: SSD1306 OLED, Nokia 5110, TP4056, ULN2003, 74HC logic
  • Custom parts with an editor: pins, internal circuit as a diagram, slider parameters

Working

  • Share as a link, no server involved; save to a file
  • Works offline, installable as an app
  • Command palette (Ctrl+K) and shortcuts; English and Hungarian interface

For learning

  • Examples with explanatory notes: LED, button, transistor, motor, logic gates, programs
  • Simple mode: advanced parts hidden, only errors shown

Designing with Claude

Describe what you want to build: Claude places the parts, wires them, writes the program and runs the simulation – in the design you are looking at.

Built-in agent, inside the app

Chat on the Agent tab. In Discuss mode it only advises; in Build mode it makes changes after you approve. One task is one undo step, and conversations are kept per project.

Needs: your own Anthropic API key.

or

Claude Desktop or Claude Code, via MCP

With the Proofboard MCP extension Claude works with your own subscription, and the design updates live in the browser. Set it up in the app: File › Claude connection; npm package: proofboard-mcp.

Needs: a Claude subscription and Claude Desktop or Claude Code.

Who it is for

Hobby builders

Teaching

Examples explain with notes, Simple mode hides the advanced parts, and problems take you straight to where the issue is.

Questions

How much does it cost?

Nothing. Proofboard is free and its source code is public on GitHub. Only the built-in agent needs your own Anthropic API key; the Claude Desktop extension works with your existing Claude subscription.

Where are my designs stored?

In your browser's storage, on your own machine. You can save them to a file or share them as a link: the design travels inside the link, nothing is uploaded.

Do I need to install anything?

No, it runs in the browser. If you like, install it as an app (File › Install) and it works offline too.

Which controller boards does it know?

Raspberry Pi Pico W, ESP32 DevKit V1 (30 pins) and ESP32-C3 SuperMini, with their pin capabilities (ADC, strapping pins, buses). Other parts can be made with the editor, and Claude can make them too.

How accurate is the simulation?

It is a fast DC approximation made for design and debugging – currents, levels, shorts. It does not replace measuring and is not a circuit simulator like SPICE.

Does it work on a phone?

Yes, with touch: one finger to move, two to zoom. A larger screen is more comfortable.
