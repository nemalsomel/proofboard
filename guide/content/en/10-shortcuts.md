Every command is also on the **command palette**: <kbd>Ctrl</kbd>+<kbd>K</kbd> or <kbd>F1</kbd>, then type what you're looking for. The palette also places parts and opens examples. <kbd>?</kbd> shows this same table in the app.

Holding <kbd>Ctrl</kbd> shows each visible button's shortcut.

Letter keys follow the key label (on any keyboard layout), digits follow their physical position. While typing in a text field, the board shortcuts are off.

## Mouse and touch

| Gesture | Effect |
| --- | --- |
| Wheel | scroll |
| <kbd>Ctrl</kbd> + wheel | zoom |
| <kbd>Space</kbd> + drag | pan the view |
| <kbd>Shift</kbd> + click | add to the selection |
| Drag on empty space | selection box |
| One finger | scroll; drag a part to move it |
| Long press | selection box |
| Two fingers | zoom and scroll |
